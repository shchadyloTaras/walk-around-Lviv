# 🍁 Львів, який шарудить під ногами

Мобільна презентація-екскурсія Львовом: від сецесійних вілл Кастелівки до двох озер,
які колись були гіпсовим кар'єром.

**Маршрут:** вул. Генерала Чупринки → вул. Андрія Мельника → вул. Євгена Коновальця → парк «Піскові озера»

👉 **Відкрити:** https://shchadylotaras.github.io/walk-around-Lviv/

## Що всередині

- 31 зупинка з фотографіями, датами, іменами архітекторів та історіями будинків
- Повна адреса кожної будівлі — клік відкриває її на Google Maps
- Тап по фото відкриває лайтбокс: світлина повністю, без обрізки, зі стрілками й свайпом
- Де фото кілька — головне велике, деталі мініатюрами під ним
- Незрозумілі слова підкреслені: тап відкриває коротке пояснення
- 4 розділи — по одному на кожну вулицю, кожен зі своєю кольоровою тональністю
- Панель маршруту з мініатюрами: можна стрибнути на будь-яку зупинку
- Прогрес-смуга, що заповнюється по ходу прогулянки
- Осінній настрій: тепле тонування фото, падаюче листя, рукописні нотатки

## Як користуватися

Гортайте вгору — слайд за слайдом. Кнопка ☰ згори праворуч відкриває повний маршрут.
На комп'ютері працюють стрілки ↑ ↓, на телефоні — звичайне гортання.

## Технічно

Статичний сайт без збірки та залежностей: HTML + CSS + трохи JavaScript.

    index.html
    assets/css/style.css     оформлення
    assets/js/data.js        зміст екскурсії (усі зупинки)
    assets/js/app.js         рендер, навігація, лайтбокс, листя
    assets/js/credits.js     автори фотографій
    assets/img/              світлини

Щоб запустити локально:

```bash
python3 -m http.server 8777
```
